## Parts of a Linux system

- Kernel
    - Hardware, memory, and running programs
- Desktop
    - Windows, menus, and settings
- Apps and a package manager
    - Everyday tasks, software installation, and updates
- A distribution puts these pieces together

---

## Linux distributions

- Ubuntu is based on Debian
    - Mainstream Mint is based on Ubuntu
    - Kubuntu is an official Ubuntu flavor
- Mint also has a Debian-based edition, LMDE
- Other families include Fedora, Arch, and Slackware

## Desktop environments

- Ubuntu uses GNOME
- Kubuntu uses KDE Plasma
- Linux Mint Cinnamon uses Cinnamon
- Many distributions offer a choice of desktops

---

## Updates and support

- Debian Stable and Ubuntu Long Term Support
    - Most apps stay on the same major version
    - Security fixes and other updates still arrive
- Newest app versions may take longer
