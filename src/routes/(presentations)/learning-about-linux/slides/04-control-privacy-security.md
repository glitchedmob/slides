## Customization

- Choose your desktop and apps
- Change how things look and behave
    - Layout, fonts, keyboard shortcuts
- Open-source code can be changed and shared
    - You can use someone else's changes

---

## Open-source licensing

- Linux kernel uses GPL version 2
    - Use, modify, and share under its terms
    - Share source when distributing modified versions
- Distributions can include closed-source apps and drivers
- Anyone can inspect open-source code

---

## Privacy and telemetry

- Windows collects diagnostic data
    - Some required, some optional
- Linux policies depend on the distribution
    - Ubuntu offers system reporting with consent controls

---

## Antivirus

- No single replacement for Windows Defender
- Many home users don't run a separate scanner
    - Still useful for shared files or workplace requirements
- Linux can get malware too
