## Steam and Proton

- Some games have Linux versions
- Wine runs compatible Windows software
- Proton builds on Wine for Steam games
    - Used on Steam Deck and Linux PCs

---

## Will my games work?

- Steam Deck compatibility ratings
- ProtonDB reports from Linux players
- Anti-cheat can rule a game out
    - Easy Anti-Cheat and BattlEye need developer support
    - Windows kernel-level anti-cheat won't work with Proton

---

## AMD and NVIDIA

- AMD drivers usually come with Linux and Mesa
- NVIDIA commonly needs a driver package
    - Use your distribution's driver tool
