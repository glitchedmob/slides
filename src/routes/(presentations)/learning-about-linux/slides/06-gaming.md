## Graphics drivers

- Intel and AMD
    - Open drivers usually come with your distribution
- NVIDIA can take more setup and troubleshooting
    - Driver installation and updates need more attention
    - Laptop GPU switching and some display features lag behind Windows

---

## Gaming

- Steam has native Linux games
- Proton uses Wine to run many Windows games
    - Powers Windows-game compatibility on Steam Deck
- Steam Deck ratings and ProtonDB show game compatibility
- Anti-cheat prevents some multiplayer games from working on Linux
- Some anti-cheat systems support Linux, but developers must enable it
