## Hardware drivers

- Let the operating system talk to your devices
- Many come with Linux
    - Others need extra drivers or firmware
- Newer kernels add support for newer hardware

---

## Printers, scanners, and cameras

- Basic device support may be enough
    - Many network printers use standard printing protocols
- Vendor software can be the problem
    - Scanning, ink tools, or genealogy software
    - Camera works, but page correction tools might not

---

## Older computers

- Windows 11 minimum
    - 4 GB RAM, 64 GB storage
- Mint 22.3 minimum
    - 2 GB RAM, 20 GB storage
    - Recommended: 4 GB RAM, 100 GB storage
