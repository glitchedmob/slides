## Trying Linux

- Virtual machine
    - Try Linux inside your current operating system
- Live USB
    - Boot Linux without installing it
    - Run on your own hardware

---

## Linux USB demo

- Download and verify an ISO image
    - From the distribution's website
- Open Etcher or another image writer
    - Select the ISO and USB
- Double-check the drive before writing
    - **Writing the image erases the selected USB drive**

---

## Booting from USB

- Restart and open the one-time boot menu
    - Often F12 or Esc
- Select the USB
    - Usually no permanent boot-order change needed
    - BIOS or UEFI settings also control boot order
- Try the live desktop before opening the installer

---

## Before installing

- Back up your files
- Follow your distribution's installation guide
- Replacing the OS or dual booting can erase data
